# Akan Name Generator

A modern web application that generates a user's traditional **Akan name** based on their **date of birth** and **gender**. Akan names originate from Ghanaian culture, where children are named according to the day of the week they are born.

---

## Project Description

This project allows users to:

- Enter their birth date.
- Select their gender.
- Calculate the day of the week they were born.
- Generate the corresponding Akan name.
- Display the result with animations, sound effects, and confetti.

The application is built using **HTML**, **CSS**, and **JavaScript** and demonstrates DOM manipulation, event handling, arrays, functions, input validation, and responsive web design.

## Installation

1. Clone the repository

```bash
git clone https://github.com/Drizzy676/akan-name-generator.git
```

2. Open the project folder

bash
cd akan-name-generator


3. Open **index.html** in your browser.

---

## How to Use

1. Open the application.
2. Select your date of birth.
3. Choose your gender.
4. Click **Generate Name**.
5. Wait for the loading animation.
6. View your Akan name together with the day you were born.
